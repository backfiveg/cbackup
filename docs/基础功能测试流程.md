## 准备工作

全部测试在 **Git Bash** 终端中进行。每次运行 Docker 命令时**必须加 `MSYS_NO_PATHCONV=1`**，否则 Git Bash 会把 Linux 路径转换成 Windows 路径导致报错。

为减少输入量，可以设置一个别名：

```bash
alias cbackup='MSYS_NO_PATHCONV=1 docker run --rm -v E:/tmp/cbackup-demo:/demo cbackup'
```

> **路径映射规则**：Windows 路径 `E:\tmp\cbackup-demo` 在容器内映射为 `/demo`。
> - `E:\tmp\cbackup-demo\src` → 容器内 `/demo/src`
> - `E:\tmp\cbackup-demo\bak` → 容器内 `/demo/bak`

## 测试 2：过滤备份 — 只备份 C++ 文件

```bash
MSYS_NO_PATHCONV=1 docker run --rm \
  -v E:/tmp/cbackup-demo:/demo \
  cbackup backup \
    --source /demo/src \
    --dest /demo/bak2 \
    --include "*.cpp" \
    --include "*.h" \
    --verbose
```

**代码调用链**：
```

filter.cpp:37-59   → should_include() 判断逻辑
backup.cpp:217     → filter.should_include(rel_path)
```

**过滤器规则**（`filter.cpp:37-59`）：
```
1. 先检查 exclude 列表 → 命中直接排除
2. 再检查 include 列表 → 命中则保留
3. 未指定 include    → 默认全部保留
4. 指定了 include 但未命中 → 排除
```

## 测试 4：还原 — 从备份恢复数据

**目的**：验证 restore 功能，数据能完整往返。

```bash
MSYS_NO_PATHCONV=1 docker run --rm \
  -v E:/tmp/cbackup-demo:/demo \
  cbackup restore --source /demo/bak1 --dest /demo/restored --verbose
```

**代码调用链**：
```
main.cpp:37-43          → RestoreOptions
restore.cpp:22-131      → restore_dir()
  ├── 第 51-124 行      → DFS 栈遍历
  ├── 第 82-105 行      → S_ISREG → read/write 恢复文件
  ├── 第 107-113 行     → S_ISLNK → readlink+symlink
  └── 第 115-121 行     → 特殊文件恢复
```

**预期输出**：
```
[INFO] Restored: /demo/restored/hello.txt
[INFO] Restored: /demo/restored/data/config.json
... (共 18 行)
[DONE] Restore complete: 18 files, 0.10 MB
```

**完整性验证**：
```bash
# 逐文件对比 (源 vs 还原)
diff -r /e/tmp/cbackup-demo/src /e/tmp/cbackup-demo/restored
# 预期: 无差异输出

# 单独验证内容
diff /e/tmp/cbackup-demo/src/hello.txt /e/tmp/cbackup-demo/restored/hello.txt

diff /e/tmp/cbackup-demo/src/data/config.json /e/tmp/cbackup-demo/restored/data/config.json
echo "config.json: $?"  # 应为 0

diff /e/tmp/cbackup-demo/src/projects/main.cpp /e/tmp/cbackup-demo/restored/projects/main.cpp
echo "main.cpp: $?"  # 应为 0
```

**预期结果** ✅：
- 18 个文件全部恢复
- `diff -r` 完全一致（递归对比无差异）
- 每个文件的退出码都是 0

## 测试 5：打包 + 解包往返

**目的**：验证 pack/unpack 功能正常（此项不属于 backup/restore，但属于基本的全流程测试）。

**打包**：
```bash
MSYS_NO_PATHCONV=1 docker run --rm \
  -v E:/tmp/cbackup-demo:/demo \
  cbackup pack -z --source /demo/src --dest /demo/test.cbk --verbose
```

**预期**：生成 `/demo/test.cbk`，条目数 19（含目录 entry），约 102KB。

**解包**：
```bash
MSYS_NO_PATHCONV=1 docker run --rm \
  -v E:/tmp/cbackup-demo:/demo \
  cbackup unpack --file /demo/test.cbk --dest /demo/unpacked --verbose
```

**验证往返**：
```bash
diff -r /e/tmp/cbackup-demo/src /e/tmp/cbackup-demo/unpacked
# 预期: 无差异
```

## 测试 6：错误处理

**目的**：验证异常输入能被正确处理。

### 6a. 源不存在
```bash
MSYS_NO_PATHCONV=1 docker run --rm \
  -v E:/tmp/cbackup-demo:/demo \
  cbackup backup --source /demo/NOTEXIST --dest /demo/bak
```

**预期**：
```
[ERROR] Source does not exist: /demo/NOTEXIST
```
退出码 = 1

**代码位置**：`backup.cpp:161-163`
```cpp
if (!path_utils::exists(opts.source)) {
    Logger::error("Source does not exist: " + opts.source);
    stats.exit_code = 1;
    return stats;
}
```

### 6b. 缺少必须参数
```bash
MSYS_NO_PATHCONV=1 docker run --rm \
  -v E:/tmp/cbackup-demo:/demo \
  cbackup backup
```

**预期**：
```
backup/restore requires --source and --dest
```
退出码 = 1

**代码位置**：`cli_parser.cpp:147-153`

### 6c. 还原时 source 不是目录
```bash
MSYS_NO_PATHCONV=1 docker run --rm \
  -v E:/tmp/cbackup-demo:/demo \
  cbackup restore --source /demo/src/hello.txt --dest /demo/bad_restore
```

**预期**：
```
[ERROR] Backup source is not a directory: /demo/src/hello.txt
```
退出码 = 1

## 快速一键测试

将所有测试合并为一条命令，在 Docker 容器内运行：

```bash
MSYS_NO_PATHCONV=1 docker run --rm -v E:/tmp/cbackup-demo:/demo \
  --entrypoint /bin/bash cbackup:latest -c '
GREEN="\033[32m"; RED="\033[31m"; RESET="\033[0m"
PASS=0; FAIL=0
check() {
    if [ $? -eq 0 ]; then echo -e "  ${GREEN}✅ PASS${RESET} $1"; ((PASS++))
    else echo -e "  ${RED}❌ FAIL${RESET} $1"; ((FAIL++)); fi
}

echo "=== 测试1: 基本备份 ==="
/workspace/build/cbackup backup --source /demo/src --dest /demo/bak1 --verbose > /dev/null
check "基本备份"
echo "文件数: $(find /demo/bak1 -type f | wc -l)"

echo "=== 测试2: 过滤备份 ==="
/workspace/build/cbackup backup --source /demo/src --dest /demo/bak2 --include "*.cpp" --include "*.h" --verbose > /dev/null
check "过滤备份"
echo "文件数: $(find /demo/bak2 -type f | wc -l) (预期: 5)"

echo "=== 测试3: 排除过滤 ==="
/workspace/build/cbackup backup --source /demo/src --dest /demo/bak3 --exclude "*.tmp" --exclude "*.o" --exclude "*.log" --verbose > /dev/null
check "排除过滤"

echo "=== 测试4: 还原 ==="
/workspace/build/cbackup restore --source /demo/bak1 --dest /demo/restored --verbose > /dev/null
check "还原"
diff -rq /demo/src /demo/restored 2>/dev/null
check "还原内容 diff 一致"

echo "=== 测试5: 错误处理 ==="
/workspace/build/cbackup backup --source /NOTEXIST --dest /demo/bak > /dev/null 2>&1
[ $? -ne 0 ]; check "不存在的源路径报错"

/workspace/build/cbackup backup > /dev/null 2>&1
[ $? -ne 0 ]; check "缺少参数报错"

echo ""
echo "===================="
echo -e "通过: ${GREEN}$PASS${RESET}  失败: ${RED}$FAIL${RESET}"
echo "===================="
'
```
