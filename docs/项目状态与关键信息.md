## 5. 已修复的问题

- **文件**: `.devcontainer/devcontainer.json`
- **修复**: 添加 `libssl-dev` (AES), `python3`, `python3-pip`, `flask` (Web GUI)

### 5.2 cron 子命令不支持加密/过滤参数

- **修复**: `CronConfig` 新增 `compress_algo`, `cipher_algo`, `password`, `filter` 字段；lambda 改为从 CronConfig 读取，不再捕获变量

### 5.3 PackOptions::filter const 限定
- **文件**: `include/pack/packer.h`
- **修复**: `FilterConfig* filter` → `const FilterConfig* filter`

### 5.4 Compress.DecompressWrongSizeThrows 测试错误
- **文件**: `tests/test_compress.cpp`
- **问题**: zlib 的 uncompress 允许 orig_len 大于实际，不会抛异常
- **修复**: 改为 `DecompressCorruptedDataThrows` — 翻转压缩数据首字节验证异常

## 7. Docker 环境

```bash
# 构建
docker build -t cbackup .

# 运行测试
docker run --rm --entrypoint bash cbackup -c "cd /workspace/build && ctest --output-on-failure"

# Web GUI (端口 8080)
docker run --rm -p 8080:8080 cbackup

# 进入容器调试
docker run --rm -it --entrypoint bash cbackup

# valgrind
docker run --rm --entrypoint bash cbackup -c "valgrind --leak-check=full ./build/cbackup_tests"
```

- 二进制路径: `/workspace/build/cbackup`

## 8. 常用命令速查

```bash
# 基础备份
cbackup backup --source /src --dest /dst

# 打包 + Huffman压缩 + AES加密 + 6维过滤 (终极命令)
cbackup pack --compress huffman --encrypt aes -p "secret123" \
    --mtime "-7d" --size "<500M" --owner root \
    --include "*.cpp" --exclude ".git/*" \
    --source /data/src --dest /data/archive.cbk

# 解包
cbackup unpack --file /data/archive.cbk --dest /restore -p "secret123"

# 定时备份 (每天凌晨2点, 保留5份)
cbackup cron --schedule "0 2 * * *" --source /src --dest /dst --keep 5

# 实时守护进程
cbackup daemon --watch /src --sync-to /dst --log /var/log/cbackup.log
```
