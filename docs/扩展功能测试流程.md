## EX-01: 特殊文件支持

### 原理

`backup.cpp` 中有 4 个专门的处理函数（第 83-149 行）：

```
lstat() 获取文件类型后:
  S_ISLNK  → backup_symlink()   → readlink() + symlink() 重建符号链接
  S_ISFIFO → backup_fifo()      → mkfifo() 重建命名管道
  S_ISCHR  → backup_device()    → mknod() 重建设备文件
  S_ISBLK  → backup_device()    → mknod() 重建设备文件
```

`packer.cpp` 中 `classify()` 函数（第 39-47 行）将这 5 种类型编码到 `EntryType` 枚举中存入归档。

## EX-02: 元数据保留

### 原理

`backup.cpp` 第 63-76 行的 `copy_regular_file()`：

```cpp
if (preserve_metadata) {
    fchown(fd, st.st_uid, st.st_gid);   // 还原所有者
    fchmod(fd, st.st_mode & 07777);      // 还原 rwx 权限
    struct timespec times[2];
    times[0] = st.st_atim;               // 访问时间
    times[1] = st.st_mtim;               // 修改时间
    utimensat(AT_FDCWD, path, times, 0); // 写入时间戳
}
```

## EX-07: inotify 实时同步守护进程

### 测试 6.1: 守护进程启动 + 实时同步

```bash
MSYS_NO_PATHCONV=1 docker run --rm --entrypoint /bin/bash cbackup:latest -c '
mkdir -p /tmp/dtest/src /tmp/dtest/dst

# 后台启动 daemon
echo "=== 启动守护进程 ==="
/workspace/build/cbackup daemon \
  --watch /tmp/dtest/src \
  --sync-to /tmp/dtest/dst \
  --verbose &
DAEMON_PID=$!
sleep 2  # 等待守护进程初始化

echo "守护进程 PID: $DAEMON_PID"
echo ""

# 创建文件
echo "=== 创建新文件 ==="
echo "new file content" > /tmp/dtest/src/newfile.txt
sleep 1

echo ""
echo "=== 检查同步结果 ==="
if [ -f /tmp/dtest/dst/newfile.txt ]; then
    echo "✅ newfile.txt 已被同步"
    echo "内容: $(cat /tmp/dtest/dst/newfile.txt)"
else
    echo "❌ newfile.txt 未被同步"
fi

# 修改文件
echo ""
echo "=== 修改文件 ==="
echo "updated content" > /tmp/dtest/src/newfile.txt
sleep 1
echo "更新后内容: $(cat /tmp/dtest/dst/newfile.txt 2>/dev/null || echo 未同步)"

# 删除文件
echo ""
echo "=== 删除文件 ==="
rm /tmp/dtest/src/newfile.txt
sleep 1
if [ -f /tmp/dtest/dst/newfile.txt ]; then
    echo "❌ 目标文件未被删除 (inotify 可能只同步新增/修改)"
else
    echo "✅ 目标文件已被删除"
fi

# 清理
kill $DAEMON_PID 2>/dev/null || true
'
```

**预期** ✅：
- 创建文件后：`newfile.txt` 被同步到 `dst/`

**Cron 表达式解析** (`cron_scheduler.cpp:22-52`)：

```cpp
static std::vector<int> parse_field(const std::string& field, int min_val, int max_val) {
    if (field == "*") {
        // 全部值: [0, 1, 2, ..., 59]
        for (int i = min_val; i <= max_val; ++i) result.push_back(i);
    }
    else if (field.rfind("*/", 0) == 0) {
        // 步进: "*/5" → [0, 5, 10, 15, ..., 55]
        int step = std::stoi(field.substr(2));
        for (int i = min_val; i <= max_val; i += step) result.push_back(i);
    }
    else {
        // 逗号分隔 + 范围: "1,3,5-7" → [1, 3, 5, 6, 7]
        // ...解析并排序...
    }
    return result;
}
```

**下次触发时间计算** (`cron_scheduler.cpp:90-104`)：

```cpp
time_t next_trigger(const std::string& cron_expr, time_t from_time) {
    CronExpr ce = parse_cron(cron_expr);       // 解析5字段
    time_t t = (from_time / 60 + 1) * 60;      // 向上取整到下一分钟
    for (int i = 0; i < 366 * 24 * 60; ++i, t += 60) {  // 最多搜索1年
        struct tm* tm_info = localtime(&t);
        if (matches_cron(ce, *tm_info)) return t;  // 命中则返回
    }
    return -1;  // 一年内无匹配
}
```

**淘汰策略** (`cron_scheduler.cpp:106-137`)：

```cpp
void evict_old_backups(const std::string& dest_dir, int keep) {
    if (keep <= 0) return;   // keep=0 表示不淘汰
    // 1. 收集所有 .cbk 文件及其 mtime
    // 2. 按 mtime 升序排序 (最旧的在前)
    // 3. 删除最旧的直到只剩 keep 个
    while (entries.size() > keep) {
        std::filesystem::remove(entries.front().second);
        entries.erase(entries.begin());
    }
}
```

### 关键代码详解

**双 fork 守护进程化** (`inotify_daemon.cpp:157-196`)：

```cpp
pid_t pid = fork();
if (pid > 0) {
    // 父进程立即返回，打印守护进程 PID
    printf("[INFO] cbackup daemon started (PID: %d)\n", pid);
    return 0;
}
// 第一子进程
setsid();              // 脱离终端，成为会话首进程
pid_t pid2 = fork();   // 再次 fork
if (pid2 > 0) _exit(0); // 第一子进程退出，第二子进程成为孤儿 → 由 init 收养

// 第二子进程 (实际守护进程)
dup2(log_fd, STDOUT_FILENO);  // stdout → 日志文件
dup2(log_fd, STDERR_FILENO);  // stderr → 日志文件
dup2(dev_null, STDIN_FILENO); // stdin  → /dev/null
daemon_loop(cfg);             // 进入主循环
```

**递归添加 inotify 监听** (`inotify_daemon.cpp:29-52`)：

```cpp
static void add_watches_recursive(int ifd, const std::string& path,
                                   std::map<int, std::string>& wd_to_path) {
    int wd = inotify_add_watch(ifd, path.c_str(), IN_CREATE|IN_DELETE|...);
    wd_to_path[wd] = path;     // 记录 wd→路径 映射

    // 递归遍历子目录
    DIR* dirp = opendir(path.c_str());
    while ((ent = readdir(dirp)) != nullptr) {
        lstat(child);          // 不跟随符号链接
        if (S_ISDIR(st.st_mode))
            add_watches_recursive(ifd, child, wd_to_path);  // 递归
    }
}
```

**增量同步** (`inotify_daemon.cpp:55-95`)：

```cpp
static void incremental_sync(const std::string& src_path,
                              const std::string& watch_root,
                              const std::string& sync_dest) {
    std::string rel = path_utils::relative_to(watch_root, src_path);  // 计算相对路径
    std::string dst = path_utils::join(sync_dest, rel);               // 目标路径

    struct stat st;
    if (lstat(src_path.c_str(), &st) != 0) {
        if (errno == ENOENT) std::remove(dst.c_str());  // 源文件已删除 → 删除目标
        return;
    }
    if (S_ISDIR(st.st_mode)) { path_utils::mkdir_p(dst); return; }    // 目录 → 创建

    // 普通文件: 64KB 缓冲复制
    FdWrapper src_fd(open(src_path, O_RDONLY));
    FdWrapper dst_fd(open(dst, O_WRONLY|O_CREAT|O_TRUNC, 0644));
    while ((n = read(src_fd, buf, 64*1024)) > 0) write(dst_fd, buf, n);
}
```

### inotify 事件类型

| 事件 | 含义 | daemon 行为 |
|------|------|------------|
| `IN_CREATE` | 文件/目录被创建 | 文件→增量同步；目录→递归添加监听 |
| `IN_MODIFY` | 文件内容被修改 | 增量同步 (全量复制变更文件) |
| `IN_DELETE` | 文件/目录被删除 | `errno=ENOENT` → 删除目标对应文件 |
| `IN_MOVED_FROM` | 文件被移出监听目录 | 同删除 |
| `IN_MOVED_TO` | 文件被移入监听目录 | 同创建 |
| `IN_ISDIR` | 标记 (与上述组合) | 区分文件和目录事件 |

### daemon 与 cron 的区别

| 维度 | daemon (EX-07) | cron (EX-06) |
|------|---------------|--------------|
| 触发方式 | **事件驱动** (inotify 内核事件) | **时间驱动** (cron 表达式) |
| 延迟 | **实时** (毫秒级) | 分钟级 (最早下个整分钟) |
| 备份粒度 | **增量同步** (单个文件变更) | **全量打包** (整个目录) |
| 进程模型 | 双 fork 守护进程 | 前台循环 (可配合 systemd) |
| 适合场景 | 实时同步、开发环境 | 定期归档、灾难恢复 |
| 系统开销 | 持续占用内存监听 | 仅在备份时消耗资源 |
